⚠️ ¿Las imágenes NO se ven?

Posibles causas y soluciones:

1. Estás abriendo con file:// (archivo local)

Solución: Usa un servidor local. Opciones:

  • Python: python -m http.server 8000 y abre http://localhost:8000
  • Node.js: npx http-server
  • VS Code: Instala extensión "Live Server" y haz clic derecho → "Open with Live Server"

2. Las rutas son incorrectas

Verificación: Las rutas en el HTML usan images/nombre.png (relativas)

✅ Esto es correcto si la estructura es:

konscio3d-housing/
├── index.html
├── tecnologia.html
└── images/
    ├── impresora-3d-construccion.png
    └── ecosistema-konscio3d.png

3. Navegador bloqueando recursos locales

Solución: Publicar en un servidor web o usar localhost
